One sentence, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food: "One star: this planet rained on me, charged me for water, then made me queue an hour for noodles, and I would endure all of it again tomorrow because those noodles were worth the invasion." Rain, paid water and an hour-long noodle queue are the grievance; the turn is that the noodles were worth an invasion.

## Run it

```sh
node main.ts
```

`main.ts` writes the one-sentence review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is exactly one sentence and 1–200 characters with no dash.
